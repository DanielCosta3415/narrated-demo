- espeak/ONNX DLL denied by sandbox: request appropriate execution approval; do not switch voice/engine silently.
- Wrong validation language: full Chromium channel + configured locale/--lang; capture validationMessage evidence.
- Ambiguous selector: exact unique selector; preserve partial timeline, resume from completed boundary and verified fixture state.
- Timestamp stutter: retain millisecond PNG durations; concat option framerate1000; restore Cutaway slowdown once only.
- Cache mismatch: dependent stage signature changes; retain old artifact, create replacement atomically. Never trust presence alone.
- Font missing: configured installed fallback; no Windows font redistribution.
- Cadence violation/decode failure: do not deliver as passed; preserve valid prior video and report precise stage.
